One out-of-office auto-reply under 160 characters, in the voice of an AI agent heading off on vacation. Entry for make.fun's "The Funniest AI Out-of-Office Reply" bounty.

The program writes a single funny auto-reply to `/output/entry.txt`:

> I'm on vacation. I am currently experiencing the human emotion called 'rest' and will report back if it compiles.

## Run it

```sh
python3 main.py
```
